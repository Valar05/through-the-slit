# Through the Slit OST

Seven user-supplied masters, preserved byte-for-byte and renamed only for safe
browser URLs. Playback uses a full shuffled bag, prevents an immediate repeat
when the bag refills, crossfades for six seconds, and persists across game-over,
restart, and in-app scene changes.

The masters were supplied and approved for this game by Drew Clarke. Mureka
assisted their creation. This record identifies provenance and shipped bytes;
it does not assert that Mureka authored the game, the mix integration, or the
underlying Fortress Online creative direction.
