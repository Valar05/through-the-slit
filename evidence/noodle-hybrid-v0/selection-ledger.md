## Cross-synthesis hypothesis under test

The transferable core is not “pixel art plus vectors visually mixed.” It is **one semantic motion state with two render witnesses**:

- vector witness = identity, silhouette, rig, force paths, contact ownership;
- pixel witness = material, damage, grit, impact debris, quantized raster identity;
- both consume the same deterministic pose/view/force/material/damage/accessibility state.

If this survives review, it allows hand-authored vector economy, crunchy raster game identity, deterministic export, and a clean LoRA/Velora labeling boundary without asking a generative model to infer the rules after the fact.
